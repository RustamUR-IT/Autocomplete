# FlowKit – 10-Minuten-Testliste

Nach jedem Update einmal durchgehen. Bei einem ❌: Screenshot vom Fehler **und** von Einstellungen → Funktionen (ganz unten: „Diagnose Kopieren“ und „Letzter abgefangener Fehler“) schicken.

## 0. Grundlage (1 min)
- [ ] FlowKit öffnen → oben steht **✅ Alles aktiv**
- [ ] Sonst: Einstellungen → Bedienungshilfe → FlowKit an (ausgegraut? App-Info → ⋮ → Eingeschränkte Einstellungen zulassen)
- [ ] Akku: Einstellungen → Apps → FlowKit → Akku → **Nicht eingeschränkt**

## 1. Text-Kürzel (1 min)
- [ ] In Google Keep `;ty` tippen → wird zu „Danke für deine Nachricht!“
- [ ] `;date` → heutiges Datum
- [ ] `;main` → C-Grundgerüst, Cursor steht in der Mitte

## 2. Vorschläge (2 min)
- [ ] WhatsApp-Chat öffnen, **ins Feld tippen** (Tastatur geht auf) → ggf. Chips direkt über dem Feld
- [ ] Tastatur schließen → Chips verschwinden sofort
- [ ] Nachricht tippen und senden → Chips verschwinden, nichts bleibt mitten im Chat hängen
- [ ] Lieblingsantwort für eine Person anlegen → in ihrem Chat erscheint sie als roter Chip
- [ ] Einen Chip lange drücken → „wird nicht mehr vorgeschlagen“, Chip verschwindet

## 3. Kopieren (1 min)
- [ ] In Chrome doppelt auf einen Absatz tippen → „📋 Kopiert: …“
- [ ] In Spotify/WhatsApp doppelt tippen → **nichts** wird kopiert (Liken/Skippen funktioniert normal)
- [ ] Kachel „Text kopieren“ antippen → auf Text tippen → kopiert; Kachel → **halten** auf Bildschirm → alles kopiert

## 4. Dokumente & Garantien (3 min)
- [ ] Startseite → 📁 Dokumente & Garantien → „+ Datei“ → PDF wählen → Kategorie wird vorgeschlagen
- [ ] Dieselbe Datei nochmal hinzufügen → **kein Duplikat** in der Liste
- [ ] In einer anderen App (z. B. Dateien) PDF → Teilen → „In FlowKit-Tresor speichern“
- [ ] Tab „Gefunden“ → Ordner „Download“ freigeben → Funde erscheinen, Datum „vom …“ stimmt
- [ ] Beleg lange drücken → „Garantie dazu anlegen“ → Kaufdatum & Händler vorbelegt
- [ ] Garantie mit Kaufdatum vor 23 Monaten anlegen → Liste zeigt ⚠️ „noch … Tage“
- [ ] Liste zeigt Vorschaubilder bei Fotos und PDFs
- [ ] Dokument lange drücken → „Mehrere auswählen“ → 2 antippen → „Teilen“ öffnet z. B. WhatsApp mit beiden Dateien
- [ ] „💾 Als ZIP sichern“ → Datei in Drive/Downloads speichern

## 5. Rest (2 min, nur was du nutzt)
- [ ] Study Mode starten → Timer in der Benachrichtigung, „Nicht stören“ an
- [ ] Instagram öffnen → Habit-Friction-Bildschirm mit Wartezeit
- [ ] Einstellungen → Backup speichern → Datei liegt in Drive/Downloads

## Bekannte Grenzen
- Vorschläge brauchen ein paar Tage Lernzeit; am Anfang erscheinen absichtlich wenige.
- Doppeltippen klappt nur, wo die App das Antippen meldet – sonst Kachel nutzen.
- Tresor-Dateien sind nicht im JSON-Backup enthalten.
